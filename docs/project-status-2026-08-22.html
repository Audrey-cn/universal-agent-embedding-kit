FAQ

现在可以说项目“完成”吗？

可以说“本轮仓库健康加固完成，本地可合并”。不应说“已生产发布”或“已外部验证”。

99/100 是生产就绪度吗？

不是。它是本地 capability scorecard 的当前口径，总状态仍为 partial；远程 CI、发布、外部 baseline 和大规模 live evidence 是独立门禁。

接入能力完整吗？

主要形态完整：CLI、Python import/API、HTTP API 和 MCP server。新增的 uaek-mcp 已在 clean wheel 和仓库外 cwd 中验证。但真实外部 provider 凭据、host GUI 配置与生产网络安全仍需部署方处理。

为什么 ChromaDB 被移除？

它的当前支持依赖图带来无法在本项目内修复的已知风险。当前 supported 存储是 SimpleBackend，memory extra 仅保留 sentence-transformers。

本地 CI 通过为什么还要 PR？

因为当前 GitHub Actions 成功记录对应旧 main commit，并不能证明新的 workflow、dependency audit 和 release gate 在远程 runner 上也成立。
