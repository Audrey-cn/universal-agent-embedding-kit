# UAEK 0.2 Release Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a coherent `0.2.0rc1` release candidate whose public version surfaces,
documentation, audit evidence, focused coverage gates, wheel, and remote-CI references agree.

**Architecture:** Add one runtime version authority, derive audit gates from evidence instead of
hard-coded values, and add a small supported-module coverage checker beside the existing global
coverage floor. Keep advanced verification modules experimental in documentation rather than
expanding their implementation during release closure.

**Tech Stack:** Python 3.11+, Click, pytest/pytest-cov, Ruff, Mypy, setuptools/build, GitHub Actions.

## Global Constraints

- Preserve unrelated work and all archived benchmark evidence.
- Use `0.2.0rc1` on every public version surface.
- Every production behavior correction follows RED → GREEN.
- Documentation-only edits may be made mechanically after the behavior they describe is verified.
- Do not publish to PyPI, push, or execute credentialed providers.
- Keep the global coverage floor at 75%; add focused floors without exclusions or pragmas.
- Preserve partial proposition status and evidence caveats.

    assert any("mcp/server.py: missing" in error for error in errors)

def test_supported_coverage_accepts_recorded_floors():
