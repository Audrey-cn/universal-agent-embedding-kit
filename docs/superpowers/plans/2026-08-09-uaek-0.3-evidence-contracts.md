# UAEK 0.3 Evidence Contracts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the credential-free 0.3 evidence core: validated multi-sample campaigns grouped by
real backend family, separated warm/cold cost evidence, separated deterministic/live scenario
evidence, comparable external baselines, CLI entrypoints, audit integration, fixtures, and CI gates.

**Architecture:** Add a focused `src/evidence` package with one module per evidence contract. Reuse
the existing capability live runner for authorized execution, but keep validation and aggregation
pure so CI uses deterministic fixtures. Extend the unified audit with an optional 0.3 evidence
index; absence remains honest `not_configured` evidence rather than an audit crash.

**Tech Stack:** Python 3.11+, stdlib JSON/hashlib/statistics, Click, pytest, existing UAEK capability
grader, GitHub Actions.

## Global Constraints

- Finish and verify the 0.2 release-closure plan first.
- Use schemas `evidence_campaign_v1`, `cost_evidence_v1`, `session_evidence_v1`, and
  `external_baseline_v1` exactly.
- Never write credential values to manifests, logs, or artifacts.
- Group model evidence by `backend_family`; provider aliases do not increase family count.
- Do not count deterministic scenarios as live sessions.
- Do not combine warm, mixed, and cold cost cohorts into one headline.
- Use test-first behavior changes and deterministic fixture providers in CI.
- Do not execute paid providers, publish, push, or create releases in this plan.
